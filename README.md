# AI Content Moderation System
![Python](https://img.shields.io/badge/Python-3.11-blue)
![Flask](https://img.shields.io/badge/Flask-Backend-black)
![Machine Learning](https://img.shields.io/badge/ML-ScikitLearn-orange)

An AI-powered content moderation system that detects toxic text using Machine Learning and integrates with a Chrome extension for real-time moderation.

## Features
- Toxic comment detection
- Confidence score prediction
- Flask REST API
- Chrome extension integration
- Machine Learning based moderation

## Tech Stack
- Python
- Flask
- Scikit-learn
- JavaScript
- Chrome Extension APIs
